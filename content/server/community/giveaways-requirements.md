# Entry Requirements

Gate giveaway entries so only eligible members can join. Configure requirements when creating or editing a giveaway in [`/giveaway`](/docs/reference/commands) or `/dashboard/<id>/giveaway`.

## Supported Requirements

| Requirement | How it works |
|---|---|
| **Required Role(s)** | Entrant must hold the configured role(s) |
| **Message in Channel** | Entrant must send at least one message in a chosen channel |
| **Keyword in Message** | Entrant's message must contain a specific keyword |
| **Thread Join** | Entrant must join a specific thread |
| **Voice Channel Join** | Entrant must be connected to a voice channel |

Members who do not meet all active requirements are shown what is missing when they attempt to enter.

# Custom Canvas Cards

Design custom **1000×300** PNG cards in **Dashboard → Canvas Templates** (`/dashboard/<id>/canvas`).

![Custom Canvas Studio editor](/images/feature_custom_canvas.webm)

## Templates & Assignments

- **Built-in Defaults:** *Welcome*, *Farewell*, and *Level-Up* templates work out of the box and can be viewed in read-only mode or cloned.
- **Assign to Events:** Bind any custom template to **Welcome**, **Farewell**, or **Level-Up** (`/rank`) events.

## Layer Types

| Layer | What it renders |
|---|---|
| **Background** | Solid color, gradient, or custom image (with optional blur and overlay tint) |
| **Avatar** | Circle, rounded, or square crop, border, and Discord avatar decorations |
| **Text** | Dynamic placeholders, alignment, drop shadow, solid or gradient fill, built-in or custom uploaded fonts |
| **Progress Bar** | XP / level progress bar with `current` / `max` interpolation, border radius, and fill gradient |
| **Image** | Overlay badges, logos, or decorative graphics |

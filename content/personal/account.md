# Account & Profile

Personal Chino settings follow your Discord account everywhere: across servers, DMs, and `/me` on the web.

## Discord Panel ([`/account`](/docs/reference/commands))

| Section | What it manages |
|---|---|
| **Start** (`start`) | Onboarding checklist and quick links |
| **Profile** (`profile`) | Discord ID, language, premium tier/expiry, and **About Me** (up to 600 chars) |
| **Settings** (`settings`) | Language (`English`, `Japanese`), locale, and IANA timezone |
| **Privacy & AI** (`privacy`) | Toggles for DM reminders, activity sharing, profile visibility, **AI opt-out**, and **AI image analysis** (see [Privacy](/docs/privacy/overview)) |
| **AI Settings** (`ai`) | Personal AI character (name up to 64 chars, description 10–600 chars) and preferred model alias |
| **Premium** (`premium`) | View tier and share/unshare server slots (for up to date data, see [Pricing and Limits](/docs/reference/pricing)) |
| **What's New** (`whatsnew`) | Release notes and links to `/changelog` and `/status` |
| **Dashboard** (`dashboard`) | Direct links to web account pages |

## Web Workspace (`/me`)

- **`/me`:** Greeting, onboarding checklist, next 5 upcoming reminders, and quick links.
- **`/me/settings`:** Edit timezone, locale, privacy toggles, AI opt-out, and AI image analysis.
- **`/me/security`:** Inspect active dashboard sessions (browser, last active, expiry), revoke individual sessions, or sign out everywhere.
- **`/me/studio`:** View metadata audit log of your AI requests (timestamps, feature, model alias, tokens, duration - never prompts or answers).

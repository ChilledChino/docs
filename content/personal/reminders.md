# Reminders

Create one-off or recurring reminders that deliver via Discord DM, from any server, DM, or `/me/reminders`.

## Creating Reminders

- **In Discord ([`/remind`](/docs/reference/commands)):** Use the `create` tab with natural language (`when` + `what` up to 1,500 chars), timezone, and optional repeat rule.
- **Right-Click Context Menu:** Right-click any message → **Apps → Remind me about this**, enter when and optional timezone. **Link-only:** Chino saves only the message link, never the message text.
- **On the Web (`/me/reminders`):** Natural language input with live time preview and recurrence presets (`1d`, `1w`, or custom `h`/`d`/`w`).
- **Via AI Chat:** Ask Chino in personal or server chat to list, create, snooze, or cancel your reminders.

## Managing & Snoozing

- **DM Buttons:** When a reminder fires in DMs, click to snooze (`10m` or `1h`) or mark done.
- **Panel & Web:** Browse **Upcoming** (snooze `10m`, `1h`, `1d`, or cancel) and **History** (completed, cancelled, failed).
- **DST Anchor:** Day-step recurrences preserve your local clock time across Daylight Saving Time transitions.

# Right-Click AI Actions

With **User Install** authorized on your Discord account, you can run AI actions on any message in any server, DM, or group DM.

## Available Message Actions

Right-click any message → **Apps**:

- **Ask Chino** - Ask a custom question about the message.
- **Explain** - Explain what the message means.
- **Summarize** - Summarize a long message.
- **Translate** - Translate the message.

## Behavior & Privacy

- **Ephemeral Replies:** Only you see the response.
- **Follow-Up Questions:** Click the follow-up button to ask more (1–500 chars) in a modal, or click **Source** to jump back to the original message.
- **Images:** Attached images are included up to your plan's image limit if both your personal switch and plan allow it (for up to date data, see [Pricing and Limits](/docs/reference/pricing)).
- **Opt-Out Respect:** Only the selected message is sent, and if the message's author opted out of Chino AI, the action refuses to read it.

# Entertainment & Utilities

Quick lookup, image, translation, and server inspection commands.

## Lookup & Translation

| Command | What it does |
|---|---|
| [`/define`](/docs/reference/commands) `<word>` | Up to 3 Urban Dictionary definitions with examples and vote counts |
| [`/ip`](/docs/reference/commands) `<ip>` | IPv4/IPv6 geolocation, ISP, ASN, mobile/proxy/hosting flags |
| [`/movie`](/docs/reference/commands) `<title>` | Movie search with interactive picker, poster, ratings, cast, and plot |
| [`/translate`](/docs/reference/commands) `<text> <to> [from]` | Translate text with language detection and confidence score |
| [`/info`](/docs/reference/commands) | Bot memory, uptime, shard latency/counts, and Lavalink node stats |
| [`/user info`](/docs/reference/commands) `[user]` | Member account age, join date, timeout status, roles, and permissions |

## Images

| Command | Options |
|---|---|
| [`/anime`](/docs/reference/commands) `[type]` | `hug`, `neko`, `nom`, `pat`, `poke`, `pout`, `smug`, `wallpapers`, `avatar` |
| [`/animal`](/docs/reference/commands) `[type]` | `cat`, `dog`, `fox` |
| [`/booru`](/docs/reference/commands) `<query> [site]` | NSFW only (`danbooru`, `gelbooru`, `konachan`, `yandere`, `safebooru`) |

## Server Panel ([`/server`](/docs/reference/commands))

Inspect a server in Discord with sections for **Overview** (`overview`), **Channels** (`channels` with type filter), **Roles** (`roles`), **Emojis** (`emojis`), **Icon** (`avatar`), and **Banner** (`banner`).
